🔌 Connect Meta — Facebook · Instagram · WhatsApp

One Meta App serves every tenant's Facebook Page, Instagram account and WhatsApp number. Set it up once, here — everything saves to your database, no config file and no redeploy. Tenants never see any of this; they just press "Connect" in their own Settings.

1Your public addressTo do▼

The secure (https://) address people use to reach this website. Meta only sends messages to https addresses, and every link below is built from this.

2Create your Meta App & paste its keysTo do▼
  1. Open Meta for Developers → Create App → choose Business type, name it "Baybex AI".
  2. In your new app go to App settings → Basic. Copy the App ID, and click Show next to App Secret.
  3. Paste both below. When you save, we ask Meta whether the pair is real — a wrong one is refused so it can't break anything.
The secret is also used to check that every incoming message really comes from Meta.
3Connect the webhook (how Meta delivers messages to you)To do▼

The webhook is the address Meta calls whenever a customer messages any connected Page, Instagram account or WhatsApp number. Pick a verify token (a password only you and Meta know), save, then let us register it with Meta in one click.

5WhatsApp (skip if you only sell Facebook/Instagram)To do▼
  1. In your app add the WhatsApp product → Configuration → Embedded Signup → create a configuration ("Allow people to share their own WhatsApp Business number"). Copy its Configuration ID.
  2. In Business Settings → System users create a system user, give it your app with whatsapp_business_messaging + whatsapp_business_management, then Generate token (never expires). Paste it below — one token sends for every tenant's number.
